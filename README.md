## Opombe

- **Standardi ZAPS** so sicer za prijavljene člane ZAPS, a so PDF-ji javno dostopni prek direktnih URL-jev na zaps.si.
- Za posodobljene verzije zakonov obišči [pisrs.si](https://pisrs.si) in poišči zakon po kratici.
- Za posodobljene standarde obišči [zaps.si/poklicna-praksa/standard-zaps/](https://zaps.si/poklicna-praksa/standard-zaps/).
- Za aktualni izpitni katalog obišči [zaps.si](https://zaps.si) → Praksa → Strokovni izpit.
